# Changelog

## 1.1.1

- First public-ready TaskTap release with English-only interface and documentation.
- Retain the internal `tap-toggle-task` ID.
- Guard optional Tasks API lookup.

- Preserve native cursor placement after task text, undo and Tasks recurrence.
